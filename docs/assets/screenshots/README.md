# Screenshots

README 首页截图行使用以下文件（建议竖屏、同一尺寸，例如 1080 × 2400 的 PNG）：

| 文件 | 内容 |
|---|---|
| `chat.png` | 对话页 |
| `agent.png` | 智能体执行工具 |
| `voice.png` | 语音界面 |
| `models.png` | 模型管理 |

放入后，删除 `README.md` 与 `README.en.md` 中截图注释的首尾两行（`<!--` 与 `-->`）即可显示。

The README screenshot row expects the four files above. After adding them, remove the opening and closing lines of the screenshot comment in both `README.md` and `README.en.md`.
