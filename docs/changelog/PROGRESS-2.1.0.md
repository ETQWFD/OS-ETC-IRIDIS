# IRIDIS 2.1.0（versionCode 177 → 178）

2.0.x 测试版之后的第一个正式版本，并入 2.0.1–2.0.5 全部补丁。

## ⚠️ 包名变更（升级前必读）
- 包名由 `com.iris.localai` 改为 **`com.iridis`**，**不能覆盖安装旧版**，新旧两个应用会并存。
- 迁移方法：在旧版 设置 › 备份 导出备份 → 安装 2.1.0 → 导入备份 → 确认无误后再卸载旧版。
- 工作区改到 `Download/IRIDIS`；启动时自动把旧的 `Download/IRISLocalAI` 迁移过来，并清理失效的 SAF 授权。

## 新增
- **备份导出/导入**：聊天、设置、记忆、技能等一并打包；导入前先检查并确认内容；API 密钥默认**不**导出（可手动勾选包含）。
- **消息编辑 / 重新生成 / 多版本**：可编辑提问或回复，重新生成；消息下方 ‹ n/m › 切换不同版本（分支）。
- **长期记忆**：聊天默认注入记忆；支持「记住：」/`remember:` 命令和「记住这条」；首条回复前记忆快照可重取。
- **简化知识库**：把 txt / md / html 放进 `Download/IRIDIS/knowledge` 即可；中文二元组 BM25 检索，变更检测自动重建索引；智能体按需调用 `kb_search`（只有知识库有文件时才列出该工具，提示词仍 ≤800 词元）；回复下显示「引用 n 段知识库」；设置里有状态、添加文件、重建索引、引用知识库开关。
- **浏览器搜索**：默认用谷歌（WebView），遇到验证码自动回退 Bing。
- **触感与提示音**：设置 › 外观 › 反馈，可分别开关触感和柔和提示音。
- **模型共享目录**：有「所有文件访问」权限时模型存到 `Download/IRIDIS/models`（卸载或改包名都不丢）；两处目录合并列出（同名优先公共目录）；存储页一键迁移，带进度、路径与授权提示，自动放 `.nomedia`。

## 改进
- **计划卡与工具卡中文化**：计划步骤卡按结构化状态显示，步骤标题更易读；回复里不再露出工具调用 JSON。
- **UI 简化**：回复操作栏收进 ⋯ 菜单；侧栏底部改为一行图标导航；可见文案 IRIS → IRIDIS。
- **API 修复**：客户端断开即取消生成、支持 stop 序列、回复进行中不切换模型、CORS / Expect / 错误返回修正。
- **图片输入修复**：MNN 发图卡在预填充（计数时重复视觉编码）修复；MNN 图片缩至 512px；含图整段预填充；未读到图片时报错；预填充中停止立即生效；开启知识库时图片丢失修复；WebP/HEIC 转 JPEG。
- **NPU 修复（骁龙 8 Elite SM8750 / Hexagon V79）**：SoC 基础型号统一匹配；logcat 过滤补充 NPU 关键字；NPU 专用模型首次生成失败直接显示原生错误；无 ekv 文件时按模型族估算 KV 预算；运行库完整性校验（损坏时提示「需要修复」）。

## 并入的 2.0.1–2.0.5 补丁
- 2.0.1：温度限速（设置 › 性能与资源 › 功耗，35–50°C，默认关闭）；语音识别语言精简为 自动/普通话/粤语/英语。
- 2.0.2：发图给视觉模型前缩放到长边 1024 像素，解决预填充卡住。
- 2.0.3：MNN 启用 Arm KleidiAI；8 Elite「极速」档默认 6 线程。
- 2.0.4：OpenCL 回退时显示每个候选库的 dlerror 原因。
- 2.0.5：先加载 MNN 原生库再探测 OpenCL，修复 MNN 选 GPU 总回退 CPU。
