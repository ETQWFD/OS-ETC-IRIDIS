FEATURES

为手机而生的本地 AI

推理、语音、记忆都在本机完成，飞行模式照常可用；需要联网的功能，由你手动授权。

三大推理引擎

llama.cpp（GGUF）、MNN、LiteRT-LM 自动择优：CPU、Adreno GPU、高通 NPU 按机型选最快。

LiteRT-LM 官方仅 64 位库，32 位设备自动隐藏

完全离线 · 隐私优先

对话、记忆、文件只存本机，禁止云备份。只有下载模型、开启 API 或智能体联网时才连网。

智能体与终端

读写文件、内置 Linux 终端（32/64 位 proot + Alpine）、联网搜索、定时任务，改动可撤销。

记忆与知识库

长期记忆自动注入对话；本地文档检索（txt / md / html），消息可编辑、可多版本重新生成。

本地语音

离线识别与合成，免提对话，开口即可打断；语音包在 App 内按需下载。

局域网 API

OpenAI / Ollama 兼容接口（默认 127.0.0.1:8686），手机就是模型服务器；开放局域网强制 API Key。

OS-ETC-IRIDIS v2.3.2 完整版 · 单包

GGUF + MNN + LiteRT-LM 三引擎合一，本地语音 + 智能体 + 局域网 API，32 位与 64 位手机通用。v2.3.2 新增「检查更新」功能，内置 Termux 中文核心，终端不再需要另外下载安装。

  • 检查更新：设置 › 关于 › 检查更新，自动对比 GitHub 最新版，发现新版一键下载 APK
  • 内置 Termux 中文核心（32 位）：一键下载安装，无需外部应用；下载走多镜像自动切换（GitHub + 3 个加速镜像）
  • 模型推荐库 18 个（Qwen / Llama / DeepSeek / Gemma / Phi-3 / Mistral），小模型优先适配 32 位
  • 32 位模型加载 OOM 修复：armeabi-v7a 自动限制线程与上下文，0.6B/1.5B 流畅运行
  • llama.cpp（GGUF）+ MNN 引擎：32 位 / 64 位全功能可用；LiteRT-LM + NPU：64 位自动启用
  • 支持 Android 5（API 21）至 Android 16（API 36）
