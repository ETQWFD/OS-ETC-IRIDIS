OS-ETC-IRIDIS 使用手册

一站式安卓本地 AI 平台 · 离线运行 · 32 位 / 64 位手机都能用。本手册涵盖安装、模型、智能体、记忆、语音、局域网 API 与常见问题，内容以 v2.2.1-etc 实测行为为准。

01 关于本手册与项目

OS-ETC-IRIDIS 是开源项目 IRIDIS（作者 WWRJ3321）的 ETC 分支：完整保留原作者的一切功能与版权，在此基础上由 ETQWFD 维护，新增 armeabi-v7a（32 位）支持，让 32 位 / 旧款 / 低配安卓手机也能正常安装运行（GGUF、MNN、语音、智能体终端均可用）。

推理、语音、记忆全部在手机本地完成，数据不出手机；只有下载模型 / 语音包 / 运行库、智能体主动联网、或你手动开启局域网 API 时才联网。

有任何问题，请发送这个邮箱给开发者：2416444244@qq.com。反馈时请附上机型、安卓版本、APK 版本号（设置 › 关于）与复现步骤。

02 系统要求

项目要求
系统版本Android 5（API 21）及以上，最高兼容 Android 16（API 36）；单一安装包自动适配 32 位 / 64 位
处理器arm64-v8a（64 位）或 armeabi-v7a（32 位），单包已内置双架构
内存2 GB 可运行 1B 级模型；4 GB 建议 4B 以下；4B 以上模型建议 12 GB
存储模型体积即所需空间（例如 3.8 GB 的 Qwen 3 需要约 4 GB 空闲）
可选硬件GPU（Adreno）加速 OpenCL；高通骁龙 8 系可启用 NPU（仅 64 位）

32 位设备推荐使用 4B 以下模型以保持流畅；LiteRT-LM 引擎官方只提供 64 位库，32 位设备会自动隐藏该引擎，GGUF 与 MNN 不受影响。

03 安装与升级

首次安装

  1. 从 GitHub Releases 下载 OS-ETC-IRIDIS APK（单一安装包，同时支持 32 / 64 位，约 40 MB）。
  2. 安装时允许「安装未知来源应用」的提示。
  3. 打开 App，在「模型管理」下载或导入模型后即可对话。

从旧版 IRIS LocalAI 升级

2.1.0 起包名改为 com.iridis，与旧包（com.iris.localai 等）不同，不能直接覆盖安装，否则会提示安装失败。请先打开旧版「设置 › 存储 › 备份与恢复」导出备份，再安装新版并在「设置 › 存储空间 › 备份与恢复」导入。

工作区位置

工作区默认在公共目录 /storage/emulated/0/Download/IRIDIS（可在文件管理器直接看到）。授予「全部文件访问」后模型等大文件都放这里；未授予时使用应用专属目录 Android/data/com.iridis/files/，两个位置都会在应用内列出。

04 模型管理

引擎格式硬件32 位
llama.cpp.ggufCPU / GPU（OpenCL）支持
MNN-LLMMNN 模型文件夹CPU / GPU（OpenCL）支持
LiteRT-LM.litertlmGPU / 高通 NPU不支持（自动隐藏）
  • 下载模型：在「模型管理」的在线列表中选择并下载（需要网络）；下载进度可暂停。
  • 导入模型：把 GGUF 文件拷入 Download/IRIDIS/models（或应用专属目录），MNN 模型以文件夹形式放入同一目录，应用会自动扫描。
  • 移动与删除：在「模型管理」可将私有目录模型移动到公共目录（不合并同名文件）；删除前会二次确认。
  • NPU：仅骁龙 8 系 64 位设备可用；首次使用需在应用内同意高通许可并下载 QNN 运行库（不随 APK 分发）。

05 对话与推理

  • 新建对话：列表页右上角新建；每个对话独立上下文。
  • 采样参数：在「设置 › 生成」调整 temperature / top_p / top_k / min_p / repeat_penalty 等；单条消息也可临时指定。
  • 思考模式：推理模型默认展示思考过程（reasoning_content），可在设置关闭。
  • 编辑与重新生成：长按或点击消息可编辑、可重新生成多个版本，历史版本可回退。
  • 继续生成：生成中断后可「继续」补写。
  • 性能调校：KV 缓存复用让后续轮次更快；空闲时按设置自动卸载模型释放内存；「设置 › 性能与资源」可切换资源档。
AI 输出可能出错，请勿用于医疗、法律、金融等重要决策。智能体可以执行命令与联网，只对信任的内容开启。

06 智能体与终端

在对话页开启「智能体」后，模型可以调用工具完成任务：

  • 文件工具：在工作区内读写、移动、删除文件（沙箱限制在工作区内，路径经检查）。
  • 内置终端：Linux 终端 提供 proot + Alpine Linux 环境，32 位设备自动使用 armv7 根文件系统，64 位使用 aarch64；终端内改动可撤销。Alpine 根文件系统与 QNN 运行库默认从北京清华镜像源下载，国内速度更快。
  • 外部终端（可选）：可对接 Termux 获得完整 Linux 环境。32 位手机请安装 ZoneTermux32（Termux 官方已停止 32 位支持，ZoneTermux32 是持续维护的 32 位分支），64 位手机可使用官方 Termux。安装后在 Termux 中运行 termux-setup-storage 并允许外部应用调用即可。
  • 联网搜索：模型主动请求后经你确认才联网（默认不联网）。
  • 定时任务：可安排周期任务（如每天提醒），任务执行前会先征得确认。
  • 备份：设置 › 存储空间 › 备份与恢复，一键导出 / 导入工作区与配置。
终端拥有工作区文件权限，请勿授予关键系统目录；只对信任的对话开启智能体。

07 记忆与知识库

  • 长期记忆：对话中的要点自动沉淀为记忆，后续对话自动注入；可在设置查看与清理。
  • 知识库：把 txt / md / html 文档放入工作区 knowledge 目录，在「上下文与记忆」中重建索引后即可检索引用。
  • 上下文窗口：可调整最大上下文长度；超长对话会自动摘要压缩。

08 本地语音

  • 离线识别：首次使用按提示下载语音包（sherpa-onnx），之后完全离线识别。
  • 离线合成：朗读回复同样本地完成。
  • 免提对话：语音模式开口即可打断，说完自动识别发送。
  • 管理：语音包与引擎状态在「设置 › 语音」查看；删除语音包可释放空间。

09 局域网 API

在「设置 › API 服务」开启后，手机就是一个 OpenAI / Ollama 兼容的模型服务器，默认端口 8686：

  • Base URL：http://127.0.0.1:8686/v1（本机）；开启「允许局域网访问」后显示局域网地址（如 http://192.168.1.23:8686/v1）。
  • OpenAI 兼容：GET /v1/models、POST /v1/chat/completions（支持流式 SSE）。
  • Ollama 兼容：GET /api/tags、POST /api/chat。
  • 健康检查：GET /health（无需鉴权）。
  • API Key：仅本机访问时可不设；开启局域网后强制使用（格式 sk-iris-…，可在页面重新生成）。带 Origin 头的浏览器 / 插件请求即使本机也必须带 Key，否则 403。
  • 生成请求与应用内对话共用模型并排队，客户端断开会立即取消，不会占用。

curl 示例

curl http://127.0.0.1:8686/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"stream":true,"messages":[{"role":"user","content":"用一句话介绍你自己"}]}'

Python 示例

from openai import OpenAI
client = OpenAI(base_url="http://192.168.1.23:8686/v1", api_key="sk-iris-...")
for chunk in client.chat.completions.create(
        model="default", stream=True,
        messages=[{"role": "user", "content": "你好"}]):
    print(chunk.choices[0].delta.content or "", end="")

更完整的接口与错误码说明见仓库内 docs/API.md。

10 性能与资源

  • 资源档：「设置 › 性能与资源」按机型选择，低档优先省电。
  • 空闲卸载：对话空闲一段时间后自动释放模型内存。
  • 温度限速：机身发热时自动降频保护。
  • 32 位提示：armeabi-v7a 设备请用 4B 以下模型；同一模型在 64 位设备上速度更快。

11 常见问题

Q：32 位手机能装吗？

A：能。APK 同时内置 armeabi-v7a（32 位）与 arm64-v8a 原生库，32 位设备自动加载 32 位库；GGUF、MNN、语音、智能体终端均可正常使用。

Q：点「开始使用」后闪退 / 黑屏回桌面？

A：旧版（v2.2.0 及更早）在 Android 5~11 手机上会因毛玻璃特效调用 Android 12+ 专属渲染 API 而闪退。请升级到 v2.2.1-etc：该版本已从代码层面彻底修复，Android 12 以下自动关闭模糊特效（界面风格不变），欢迎页之后可正常进入聊天。若升级后仍闪退，请在「设置 › 存储空间 › 崩溃记录」导出日志发邮件给开发者。

Q：为什么我的设备里没有 LiteRT-LM 引擎？

A：LiteRT-LM 官方只有 64 位库且要求 Android 7（API 24）以上。32 位设备或 Android 5/6 会自动隐藏该引擎，GGUF 与 MNN 不受影响，功能完整可用。

Q：模型放哪里？为什么 App 里不显示？

A：模型放在 Download/IRIDIS/models（全部文件访问）或应用专属 files/models。若放错目录或格式不匹配（如 MNN 用了 .gguf），App 不会显示；请在「模型管理」查看实际扫描到的目录。

Q：内存不足 / 很卡怎么办？

A：换更小的模型（如 1B），或在「设置 › 性能与资源」调低资源档并开启空闲卸载；关闭并行对话。

Q：NPU 用不了？

A：NPU 仅骁龙 8 系 64 位设备支持，且需在应用内同意高通许可并下载 QNN 运行库。其他设备自动回退 GPU / CPU。

Q：API 返回 403 / 401？

A：来自浏览器 / 插件的请求必须带 API Key；局域网访问必须在设置中开启并配置 Key。本机 127.0.0.1 未开局域网时可不带 Key。

Q：升级提示安装失败？

A：2.1.0 起包名为 com.iridis，与旧版包名不同无法覆盖。先备份（设置 › 存储空间 › 备份与恢复），卸载旧版后安装新版再导入备份。

Q：可以完全离线使用吗？

A：可以。首次下载模型与语音包后，推理、语音、记忆全部离线；App 不会在后台静默联网。
